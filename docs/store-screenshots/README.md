# Google Play phone screenshots

These five 1080 × 2400 PNGs were captured directly from the signed Bible Door
1.0.2 (build 3) APK on the Android 16 / API 36 phone emulator on 26 October 2026.
They are unedited screen captures, including Android's status and navigation bars.

- `phone-welcome.png`: first launch.
- `phone-library.png`: adding Bibles and the free-Bible demo link.
- `phone-reader.png`: real WEBBE Titus text downloaded using `webbe-123-456`.
- `phone-settings.png`: reading preferences and Privacy below About.
- `phone-about.png`: app version and the Freely-Given.org / OET.Bible links.

The WEBBE text is public domain. No private Bible keys, personal reading data,
or signing credentials appear in these images. The separate `docs/screenshots/`
folder contains Flutter layout previews, including tablet layouts.
